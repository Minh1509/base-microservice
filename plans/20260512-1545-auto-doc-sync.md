# Plan: Auto doc sync khi project thay đổi

## Goal

Khi AI thêm feature, sửa architecture, hoặc thay đổi bất kỳ thứ gì quan trọng trong codebase, AI tự động update 5 docs sống mà không cần user nhắc.

## Context

- Hook infrastructure đã có đầy đủ: `lib/hook-logger.cjs`, `lib/ck-config-utils.cjs`, `lib/context-builder.cjs`
- `PostToolUse` hook hiện tại đã có 3 hooks: `post-edit-review.cjs`, `post-edit-simplify-reminder.cjs`, `write-checkpoint.cjs` — tất cả đều là skeleton 1 dòng
- `settings.json` đã wire `PostToolUse` matcher `Edit|Write|MultiEdit` → chạy 3 hooks trên
- Hook inject text vào conversation qua stdout JSON `{ "continue": true, "hookSpecificOutput": "..." }` — AI đọc và hành động trong cùng session
- `.claude/config/adf-config.json` tồn tại — dùng để enable/disable hook
- 5 docs cần sync (tất cả đã tồn tại, hiện là skeleton):
  1. `CLAUDE.md` — source of truth, inject mọi session
  2. `.claude/context/service-map.md` — services, patterns, ports
  3. `.claude/context/backend-architecture.md` — flow, layers, connections
  4. `.claude/memory/architecture-decisions.md` — why decisions
  5. `.claude/memory/known-issues.md` — bugs, workarounds (file đã tồn tại)

## Approach

Implement `post-edit-review.cjs` (đã được wire trong `settings.json`) thành hook phát hiện loại thay đổi và inject reminder có cấu trúc để AI update đúng docs.

Hook đọc `tool_input` từ stdin (path file vừa sửa), map path → docs cần update bằng regex cụ thể, inject message ngắn gọn. AI nhận message và update docs ngay trong cùng turn.

**Dedupe theo session:** dùng temp file `os.tmpdir()/ck-doc-sync-<sessionId>.json` lưu set các category đã inject trong session. Cùng category chỉ inject 1 lần/session, tránh spam khi có nhiều edit nhỏ.

**Skip non-semantic change:** hook chỉ inject khi file match pattern AND không phải `.claude/` directory (tránh loop khi AI update chính docs đó).

Không tạo hook mới — tận dụng slot `post-edit-review.cjs` đã có sẵn trong settings.json.

## Steps

- [ ] 1. Implement `post-edit-review.cjs`:
  - Đọc stdin JSON, lấy `tool_input.file_path` (Write) hoặc `tool_input.path` (Edit/MultiEdit)
  - Skip nếu path nằm trong `.claude/` (tránh loop khi AI update docs)
  - Map path → trigger category bằng regex theo bảng dưới
  - Nếu không match → exit 0, không inject gì
  - Kiểm tra dedupe: đọc `os.tmpdir()/ck-doc-sync-<sessionId>.json`, nếu category đã inject trong session → skip
  - Nếu chưa inject → ghi category vào dedupe file, inject reminder JSON

- [ ] 2. Thêm `post-edit-review: true` vào `hooks` section trong `.claude/config/adf-config.json`

- [ ] 3. Verification — chạy 4 test case:
  - **Match:** sửa `apps/auth-service/entities/user.entity.ts` → hook inject reminder về `service-map.md`, `architecture-decisions.md`
  - **Non-match:** sửa `apps/auth-service/src/auth.service.ts` → hook không inject gì
  - **Dedupe:** sửa 2 entity files liên tiếp trong cùng session → chỉ inject 1 lần
  - **Loop guard:** sửa `.claude/context/service-map.md` → hook không inject gì

> **Prerequisite:** 4 docs skeleton (`service-map.md`, `backend-architecture.md`, `architecture-decisions.md`, `known-issues.md`) cần được fill nội dung ban đầu trước khi hook này có ý nghĩa. Việc đó thuộc plan `20260512-1519-fill-claude-data.md` (Tier 4).

## Mapping: file path → docs cần update

Dùng regex match trên normalized path (forward slash, lowercase). Pattern dùng `.*` thay `*` để bắt recursive.

| Regex pattern                             | Category    | Docs cần update                                                          |
| ----------------------------------------- | ----------- | ------------------------------------------------------------------------ |
| `apps/[^/]+/entities/.*\.ts$`             | `entity`    | `context/service-map.md`, `memory/architecture-decisions.md`             |
| `apps/[^/]+/src/.*\.module\.ts$`          | `module`    | `CLAUDE.md`, `context/backend-architecture.md`, `context/service-map.md` |
| `libs/common/src/constants/patterns\.ts$` | `patterns`  | `CLAUDE.md`, `context/service-map.md`                                    |
| `libs/config/src/.*\.ts$`                 | `config`    | `CLAUDE.md`, `context/backend-architecture.md`                           |
| `apps/[^/]+/src/main\.ts$`                | `main`      | `context/backend-architecture.md`                                        |
| `docker-compose.*\.yml$`                  | `compose`   | `CLAUDE.md` (ports table)                                                |
| `apps/[^/]+/database/migrations/.*\.ts$`  | `migration` | `memory/known-issues.md`                                                 |
| `libs/[^/]+/src/index\.ts$`               | `lib-index` | `context/backend-architecture.md`                                        |

## Format reminder inject

```json
{
  "continue": true,
  "hookSpecificOutput": "📝 DOC SYNC REQUIRED\nFile changed: <path>\nUpdate these docs to reflect the change:\n- <doc1>: <what to update>\n- <doc2>: <what to update>\nDo this now before finishing the task."
}
```

## Files to change

- `.claude/hooks/post-edit-review.cjs` — implement từ skeleton → hook thực
- `.claude/config/adf-config.json` — thêm `post-edit-review: true` vào hooks section

## Out of scope

- Không implement hook mới — chỉ dùng slot đã có
- Không sửa `settings.json` — wire đã đúng
- Không auto-update `rules/` hay `skills/` — đó là deliberate docs
- Không implement AI agent chạy background — chỉ inject reminder vào conversation hiện tại
- Không fill `context/domain-glossary.md` trong task này
- Không detect non-semantic change (format/import-only) ở hook level — quá phức tạp; AI tự judge khi nhận reminder

## Risks

- Hook inject quá nhiều → tốn token. Giải pháp: dedupe theo category/session, chỉ inject 1 lần/category/session.
- Loop: AI update docs → hook trigger lại. Giải pháp: skip nếu path bắt đầu bằng `.claude/`.
- `post-edit-review.cjs` crash → workflow bị block. Giải pháp: wrap toàn bộ trong try/catch, luôn exit 0 (fail-open).
